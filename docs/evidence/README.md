# Evidence fixtures

Stable plain-text proof pages served from raw.githubusercontent.com for the on-chain end-to-end runs.
Wikipedia and other live sites change too often for validators to reach consensus on a snapshot, so the e2e
scripts only cite these files. `changed/proof.md` is edited on purpose during the "changed evidence" scenario
(version 1 is snapshotted, version 2 is live at judging time).
