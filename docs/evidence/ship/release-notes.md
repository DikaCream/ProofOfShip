# tally-cli v1.0.0 release notes

Released 2026-10-20 by the tally maintainers. This file is a stable test fixture for ProofOfShip.

## What shipped in v1.0.0

- The tally export command writes a CSV file named tally-export.csv to the current folder.
- The new --json flag prints the export as JSON on standard output instead of writing CSV.
- Exit code 0 on success, 2 on invalid input.

## Install

The README documents installation with npm: run npm install -g tally-cli and then run tally --version.
